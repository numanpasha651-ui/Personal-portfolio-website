# Personal Portfolio Website

A responsive portfolio built with plain HTML, CSS and JavaScript. No install needed.

## Structure
    portfolio-website/
    ├── index.html
    ├── css/style.css
    ├── js/script.js
    ├── images/        (put your photo and project screenshots here)
    └── README.md

## Run locally
Open `index.html` in a browser, or use the VS Code "Live Server" extension.

## Customize
Search for "Your Name", "your-username", "you@example.com" and "Your College" and replace them.
Add `resume.pdf` to the folder so the resume button works.

## Publish free
Push to GitHub, then Settings > Pages > Deploy from branch > main > Save.
